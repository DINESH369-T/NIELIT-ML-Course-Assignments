# Machine Learning using Python - NIELIT Calicut
This repository contains the practical assignments completed during the 5-day "Machine Learning using Python" course organized by NIELIT Calicut.

## About the Course
The course provided a strong balance of theoretical foundations and practical implementation for each algorithm, helping me understand how they function in real-world scenarios.

## Assignments
1. Iris Species Prediction
Objective: Developed an ML model using the KNN Classifier to predict species for a given iris flower using sepal and petal dimensions.
Key Skills: Learned data preparation, model training, and prediction logic using Scikit-Learn.

2. Wine Dataset Model Comparison
Objective: Identified the best-performing ML model for the wine dataset by comparing five different algorithms.
Algorithms Compared: Naive Bayes, Decision Tree, SVM, KNN, and Random Forest.
Methodology: Utilized K-Fold cross-validation and visualized accuracy results using boxplots to determine stability and performance.

## Final Conclusion:
Based on the comparative analysis, Random Forest was identified as the best-performing model, achieving the highest accuracy (0.983007) and the lowest standard deviation (0.025972), demonstrating superior reliability and stability compared to the other algorithms.
